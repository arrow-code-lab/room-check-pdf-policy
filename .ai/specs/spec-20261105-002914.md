### 1-3 実機（ソース）で確かめた前提

**実態と一致していた点**（直さない）:

- 点検データ（写真・入力テキスト・物件・点検者情報・PDF テンプレート）は端末内（Hive / SharedPreferences / アプリ専用フォルダ）にのみ保存。アプリ独自の HTTP 通信は無い
- 外部送信は AdMob（`google_mobile_ads`、UMP 同意）と Google Play 課金（`in_app_purchase`）のみ。Firebase・分析・クラッシュレポート SDK は無い
- 位置情報: カメラ画面を開いている間だけ取得、既定オフ、事前説明あり、設定でオフ可（`capture_location_tracker.dart`、`photo_location_disclosure.dart`）
- PDF 内の写真は Exif（撮影日時・位置・機種）を保持（`AppConstants.pdfPhotoKeepExif = true`）
- Android: `allowBackup="false"`、`data_extraction_rules.xml` で全ドメインをバックアップ・端末移行から除外
- PDF 一時ファイルは起動時に削除（`pdf_temp_cleaner.dart`）
- 権限: CAMERA / ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION。ストレージ・メディア・録音権限は明示的に除去
- 有料プラン: `room_check_pdf_pro_monthly`（月額・物件管理モードのみ）、価格はストア表示、購入の復元あり、解約はストアの定期購入画面
- 提供地域から EEA・英国・スイスを除外（spec.md）

**食い違い**（直す）:

1. パッケージ名: ポリシーは「room_check_pdf」。ストアで使う applicationId は `room.check.pdf`（`android/app/build.gradle.kts:35`）
2. 入居者モードで完了した点検はアプリ内で削除できず永久保持（`doc/spec.md:191, 385`）。ポリシー 5 章・7 章は「削除操作で削除できる」としか書いていない
3. 全データを一度に消す機能は無い。全消去の手段はアンインストール（または Android の「ストレージを消去」）だけで、7 章に十分書かれていない
4. 物件情報に住所・郵便番号が含まれる（`property.dart`）。2 章は「物件名・部屋番号等」
5. 撮影画面の水準器で加速度センサーを使う（`sensors_plus`）。権限不要・端末外へ出ないが 3 章に記載が無い
6. 日本語版の公開 URL の末尾に `/` が無い（英語版・アプリ内リンクは `/` あり）

**このリポジトリの外の問題**（直さない。§8 参照）:

- ストア掲載文・README の「インターネット接続不要」「外部送信なし」が AdMob と矛盾 → arrow-code-lab/room-check-pdf#53 で起票済み
- iOS 版はポリシー（Android 前提）に未対応（IDFA・ATT・App Store 課金・iCloud バックアップ未除外・プライバシーマニフェスト未作成）
